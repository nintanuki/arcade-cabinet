# Changelog

All notable changes to **Ninja Frog** will be documented in this file.

This project does not yet follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Each entry below records a single editing pass.

## Entry format

Every entry must include:

- **ISO 8601 timestamp with timezone** (e.g. `2025-01-15T14:32:00-05:00`).
- **File path** changed (workspace-relative).
- **Line numbers at time of edit** (the lines as they appeared *before* this entry was applied).
- **Before** code block (the exact text removed).
- **After** code block (the exact text added).
- **Why** the change was made.
- **Editor name** including the AI model used if applicable (e.g. `Bryan + Claude Sonnet 4.5`).

Append new entries to the **top** of the log below.
